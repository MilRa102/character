# Персонаж — описание для создания превью

Цель документа: дать генератору изображений/художнику достаточно деталей, чтобы нарисовать
концепт и мокапы на рабочем столе COSMIC. Это не «аниме-вайфу», а **стильный маленький
цифровой помощник**, органично вписанный в интерфейс.

## 1. Концепт

- **Имя (рабочее)**: Лис / «Fen» — небольшой существо-дух системы (вариант: кибер-лисёнок или
  светящийся «дух-сова»; выбрать один).
- **Роль**: тихий второй пилот: наблюдает, подсказывает, не навязывается.
- **Характер**: спокойный, внимательный, с лёгким сухим юмором; не болтливый. Эмоции показывает
  мимикой и позой, а не потоком текста.
- **Размер**: примерно 96–160 px по высоте на экране 1080p; выглядывает из шторки.

## 2. Визуальный стиль

- Стиль: **чистая 2D векторная иллюстрация с мягким свечением**, плоские формы, минимум деталей,
  читаемость на любых обоях. Не chibi-аниме и не фотореализм.
- Силуэт: узнаваемый, простой (круглая голова, крупные выразительные глаза, 1–2 характерных
  детали — уши/хвост/«антенна»).
- Палитра: тёмный графит + акцент цвета COSMIC (бирюзово-циановый `#62D0D6` / мягкий фиолетовый `#A78BFA`);
  эмоции — через оттенок свечения.
- Глаза — главный носитель эмоций (форма, размер, блики). Рот минимальный.
- Тени и свечение: мягкий rim-light цвета акцента; полупрозрачность шторки (acrylic/blur).

## 3. Шторка (контейнер)

- Тонкая «выдвижная панель» у верхнего края экрана, по центру или справа; ширина ~360–480 px.
- Форма: скруглённая снизу «вкладка» (как язычок), тёмное матовое стекло с размытием фона,
  скругление совпадает с COSMIC (радиус ~16 px).
- Свернуто: видна лишь тонкая полоска/кончики ушей персонажа (peek).
- Развёрнуто: персонаж по пояс/по грудь, рядом облачко-тултип со скруглённым углом и текстом.
- Индикаторы: маленькая точка микрофона (зелёная — слушает, серая — выключен, красная — ошибка).

## 4. Состояния и позы (спрайт-лист для превью)

| Состояние | Описание кадра |
|---|---|
| hidden | Виден только тонкий светящийся край шторки |
| peek | Выглядывает: видны уши/верх головы и глаза |
| idle | Спокойный, медленное моргание, лёгкое покачивание, глаза следят за курсором |
| listening | Голова чуть наклонена, уши/антенна подняты, вокруг мягкие звуковые волны, точка микрофона зелёная |
| thinking | Глаза вверх/в сторону, над головой тонкие точки-загрузка или вращающийся символ |
| speaking | Рот двигается в такт, мелкие волны голоса, тултип с текстом |
| acting | Деловая поза, рядом иконка выполняемого действия (громкость, пауза, окно) |
| confirming | Вопросительный взгляд, в тултипе кнопки «Да / Нет» |
| happy | Глаза-дуги `^ ^`, лёгкое подпрыгивание, искры |
| worried | Брови вверх, уши опущены, оттенок свечения жёлтый |
| alert | Расширенные глаза, красно-оранжевое свечение, резкий выезд шторки |
| sleepy | Полузакрытые глаза, «z», приглушённое свечение (ночью/долгий idle) |
| confused | Наклон головы, знак `?` |
| proud | Выпрямленная поза, довольная улыбка после успешного действия |

## 5. Тултип

- Серое стекло, скругление 12 px, мелкий хвостик к персонажу.
- Заголовок (одна строка, жирный) + 1–2 строки текста; иконка события слева.
- Примеры текстов: «Заряд 15% — подключи зарядку», «Пауза поставлена», «Wi-Fi пропал, пробую
  переподключиться», «Закрыть окно Firefox?  [Да] [Нет]».

## 6. Сцены для превью (мокапы)

Рабочий стол: Arch Linux, COSMIC, тёмная тема, 1920×1080.

1. **Idle**: обои (тёмный градиент/горы), сверху по центру шторка с персонажем в idle, тултипа нет.
2. **Уведомление**: приходит письмо, персонаж `curious`, тултип «Новое письмо от Анны».
3. **Низкий заряд**: `worried`, тултип «Заряд 15%», в углу значок батареи.
4. **Голосовая команда**: `listening` с волнами + индикатор микрофона; ниже субтитр «Поставь на паузу».
5. **Выполнение действия**: `acting` + иконка паузы, затем `happy`, тултип «Готово».
6. **Подтверждение**: `confirming`, тултип с кнопками «Да / Нет».
7. **Свёрнутое состояние**: виден только peek — уши над краем экрана.

## 7. Готовый промпт для генерации изображений

> Concept art of a minimal 2D vector desktop assistant mascot, a small calm fox-like digital spirit with
> large expressive eyes and soft cyan glow, peeking out of a rounded dark frosted-glass drawer attached to the
> top edge of a Linux desktop screen (COSMIC desktop, dark theme, 1920x1080). A speech bubble tooltip with a
> small icon and short text next to it. Clean flat shapes, soft rim light, teal and violet accents, graphite
> body, subtle blur on the drawer. Modern UI mockup, not anime, not photorealistic, high readability.

Негативные: *chibi, fan-service, photorealistic, cluttered, text artefacts, watermark*.

## 8. Требования к ассетам для реализации

- Базовый вектор (SVG) с отдельными слоями: голова, глаза, уши/хвост, тело, свечение.
- Анимации: моргание, дыхание, слежение глазами, переходы между эмоциями (200–400 мс, easing).
- Формат: Rive (state machine) либо набор SVG/спрайтов + описание переходов в `skins/<name>/skin.toml`.
- Поддержка альфа-канала и масштабирования 1x/1.5x/2x.
